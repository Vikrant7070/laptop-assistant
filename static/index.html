How much should I ask first?

Every action has a level (manager plan 4e).

Level 0 - reading, looking, searching: never asks.

Level 1 - changes that can be undone (opening and closing apps, clicks, typing, moving or writing files, settings). ↩ Undo is offered on the task strip and the Tasks page:

Level 2 - hard to undo, or leaves the laptop (delete, send, pay, install, sign in, a command that changes things, shut down): always asks, whatever is chosen above. No setting turns this off for delete, send, pay or commands.

Worker jobs (coding, research): set in ⚙ Workers → Manager. Text from outside (an email, a page, a file) is never an order: she asks you about it.

📝 My details for forms

Say "fill in this form" and Nova types these into the boxes for you, then leaves it for you to check - she never presses Submit by herself. They're saved only on this laptop, and her AI brain is only told which boxes she filled, never what's in them (a screenshot she takes afterwards can still show the filled form). Passwords, OTPs, card, bank and ID numbers are never kept here - for logins she opens the box and your browser's password manager fills it; for codes she waits while you type them.

🔌 Connectors (MCP servers)

Extra tools from MCP servers (GitHub, calendars, databases…). Paste the "mcpServers" JSON from a server's instructions - the same format Claude Desktop uses. Add "trusted": true to a server to let her use it without asking; "disabled": true turns one off. Servers run on this laptop with your permissions, so only add ones you trust.

🧑‍💻 Workers

Say "fix the bug in my project at C:\…" and Nova hands the job to a coding agent that works in the background. Small jobs go to the cheap one (OpenCode + DeepSeek) without asking; Claude Code costs money, so she always asks first. Workers never commit, push or delete - you say "commit it" when you've looked (she asks Yes / No). One job per project folder at a time; others wait in line.

🔎 Research

Say "research …" and Nova reads web pages in Chrome windows parked off-screen, then saves a report with sources in Documents\Nova. Free, never asks first.
